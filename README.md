# BandHeartBeat

Пульс с часов прямо на веб-камере в Discord — без OBS. Приложение берёт пульс
с часов по Bluetooth, захватывает вашу камеру, рисует рядом с головой значок
пульса и отдаёт готовую картинку как виртуальную камеру **«BandHeartBeat Camera»**.

## Скачать

На странице **Releases** два варианта:

- `BandHeartBeat_x.y.z_x64-setup.exe` — установщик (ставится для текущего
  пользователя, права администратора не нужны);
- `BandHeartBeat-x.y.z-portable.zip` — портативная версия: распакуйте в любую
  папку и запустите `bandheartbeat.exe`. Файл `BandHeartBeatCamera.dll` должен
  лежать рядом с exe.

Нужна Windows 10/11 x64 с Bluetooth LE. WebView2 уже есть в Windows 11; на
Windows 10 установщик докачает его сам.

## Как пользоваться

1. Запустите BandHeartBeat. Виртуальная камера регистрируется сама (только для
   текущего пользователя, права администратора не нужны).
2. Включите на часах трансляцию пульса. Часы ищутся постоянно в фоне;
   подошедшие часы запоминаются.
3. Внизу выберите свою камеру. Превью показывает ровно тот кадр, который
   получит Discord: 1280×720, 16:9, без обрезки (режим «Целиком»).
4. В Discord: Настройки → Голос и видео → Камера → «BandHeartBeat Camera».
   Если камеры нет в списке — полностью выйдите из Discord через трей и откройте снова.

Значок может следовать за головой (сбоку или прикреплённым к точке на лице со
своим смещением) или стоять на месте — его можно перетащить по превью.
Стили: капсула, сердце, ЭКГ, кольцо, минимал, карточка, три чиби-маскота,
десять аниме-девочек с табличкой и своя картинка (PNG/SVG).
Закрытие окна сворачивает приложение в трей; выход — из меню трея.

## Часы и браслеты

Подходит любое устройство, которое передаёт пульс через стандартный
Bluetooth-сервис **Heart Rate (0x180D)**.

**Проверено на реальном устройстве:**

| Устройство | Как включить |
|---|---|
| HUAWEI Band 10 | Трансляция пульса (HR Data Broadcast) на браслете / в Huawei Health |

**Предположительно поддерживаются** (тот же стандартный сервис, но нами не проверялись):

| Устройство | Примечание |
|---|---|
| Другие HUAWEI Band / Watch с трансляцией пульса (Band 6–9, Watch Fit, Watch GT) | функция «Трансляция пульса» |
| Honor Band / Honor Watch | аналогичная функция трансляции пульса |
| Xiaomi Smart Band / Mi Band 5–9 | трансляция пульса в Mi Fitness / Zepp Life, обычно во время тренировки |
| Amazfit (Band, GTS, GTR, Bip) | «Heart rate sharing» / трансляция пульса в Zepp |
| Нагрудные датчики: Polar H9/H10, Garmin HRM-Dual, Wahoo TICKR, Coospo, Magene | работают по стандарту, без настройки |
| Пульсометры на руку: Polar Verity Sense, Scosche Rhythm, COROS HR | работают по стандарту |
| Garmin Forerunner / Venu / Fenix | режим «Трансляция пульса» (Broadcast Heart Rate) |
| Samsung Galaxy Watch, Apple Watch | только через сторонние приложения-трансляторы пульса |

Часы не должны быть одновременно подключены к другому устройству, которое
занимает Bluetooth-соединение (например, к тренажёру).

## Устройство проекта

```
crates/core   ядро на Rust: ble, camera (Media Foundation), tracking (Windows
              FaceDetector), overlay (tiny-skia + resvg), pipeline, frame (общая
              память), settings (%APPDATA%\BandHeartBeat\settings.json), vcam (реестр HKCU)
app           Tauri 2 + Svelte 5: src-tauri — команды, src — интерфейс
vcam          DirectShow-фильтр виртуальной камеры (C++), читает кадры приложения
              из общей памяти
```

## Сборка

Нужны Rust (MSVC), Node.js и Visual Studio Build Tools.

```
vcam\build.cmd              DLL виртуальной камеры → vcam\out
vcam\test.cmd               DLL + проверка на реальном DirectShow-графе
cargo test -p bhb-core      тесты ядра
cd app && npm install
npx tauri dev               запуск в режиме разработки
npx tauri build             установщик NSIS
```

Полезные примеры ядра: `cargo run --release -p bhb-core --example capture -- out.jpg 0`
прогоняет камеру через весь конвейер и сохраняет кадр; `--example badges` рисует все стили значка.
