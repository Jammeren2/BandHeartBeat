# BandHeartBeat — самостоятельная виртуальная камера

Windows 11 x64. OBS не нужен для этой сборки. Все EXE/DLL держите вместе в постоянной папке: регистрация камеры сохраняет абсолютный путь к DLL. Удалять или переносить папку следует после удаления виртуальной камеры.

1. Запустите `BandHeartBeat.exe`. Веб-камера сама не включается.
2. В трее выберите **Установить виртуальную камеру (текущий пользователь)**. Только ваша учётная запись, без администратора/HKLM. Альтернатива из этой папки: `camera-admin.exe --register`.
3. В трее выберите **Камера: выбрать и запустить**. В подменю выберите камеру по имени; захват запускается скрыто, без консоли. Собственная виртуальная камера BandHeartBeat исключена, чтобы избежать рекурсии. Iriun и другие источники показываются, если Media Foundation их перечисляет. Для проверки без камеры выберите **Камера: демо без веб-камеры**.
4. В настройках видео Discord выберите **BandHeartBeat Virtual Camera**. Проверка живого звонка Discord не проводилась. На данный момент камера поддерживает фиксированный RGB32 640×480, 15 кадров/с (объявленный формат, не гарантия фактического FPS); совместимость потребителя зависит от согласования этого формата.
5. Остановить захват: пункт **Камера: остановить**. Удалить виртуальную камеру: **Удалить виртуальную камеру** или `camera-admin.exe --unregister`. Сначала закройте использующие её программы. Это удаляет только собственные записи HKCU этой DLL; чужие записи не перезаписываются.

Для безопасного осмотра доступных камер: `camera-producer.exe --list`. Ограниченный запуск: `camera-producer.exe --camera 0 --seconds 5`. Без физической камеры: `camera-producer.exe --mock --seconds 5`. Остановка из консоли: `camera-producer.exe --stop`. Проверка Windows FaceDetector: `camera-producer.exe --face-check`. Регистрация и захват запускаются только явными командами.

Пульс поступает из того же BandHeartBeat через `127.0.0.1:8765/telemetry`. В обычном режиме без настоящей телеметрии отображается тире и **DISCONNECTED**. В mock-режиме используется явно помеченный **DEMO · NO BAND**, 72 BPM. Поддержка Huawei Band 10 и режима стандартного HR Broadcast остаётся неподтверждённой; BLE-устройство должно предоставлять стандартный сервис 0x180D.

Windows FaceDetector ищет лицо на уменьшенном Gray8-кадре, выбирает самое большое, сглаживает позицию рядом с ним и ограничивает её рамкой. При отсутствии лица/поддержки API через 1,5 с используется угол с надписью **NO FACE · CORNER**. Это явно не слежение за головой. Короткий тест реальной камеры подтвердил захват кадров, но не подтвердил качество слежения за лицом. Анимация сердца иллюстрирует BPM, а не измеренное время каждого удара.

На проверенной USB2.0 Camera при согласованном 30/1 SourceReader выдал 21 кадр за 3,031 с (16 после первой секунды), то есть примерно 7–8 новых кадров/с. Виртуальный выход объявляет 15 кадров/с и повторяет последний кадр при более медленном источнике. Это ограниченный локальный замер, не гарантия скорости на вашей камере. CPU, память и задержка отдельно не измерялись.

Кадры не сохраняются и не отправляются по сети: только локальная разделяемая память и DirectShow. При отсутствии producer виртуальная камера показывает тестовую шахматную картинку; это не прямой эфир. Изображения и диагностические файлы с изображениями не создаются. Камера должна быть свободна от других приложений. Если доступ запрещён, приложение сообщает ошибку; настройки конфиденциальности оно не меняет.

Сборка: из корня проекта `cmd /c directshow-camera\package-msvc.cmd` (установленные VS Build Tools/SDK, Rust MSVC и локальный кэш зависимостей). C++ CRT включён статически; внешних моделей OpenCV/ONNX нет. FaceAnalysis и Media Foundation предоставляет Windows. Производительность и задержка не измерены. Старый OBS-оверлей доступен в основном приложении как запасной путь.
