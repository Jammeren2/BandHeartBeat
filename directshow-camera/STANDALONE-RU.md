# BandHeartBeat — нативная виртуальная камера

Windows 11 x64. OBS и браузер для интерфейса не нужны. Распакуйте все файлы вместе в постоянную папку. Если запущена старая версия, завершите её через «Выйти» в трее перед запуском новой. Камера не включается автоматически.

1. Запустите BandHeartBeat.exe. Выберите физическую камеру по имени справа или «Демо · без камеры» и нажмите «Запустить». Смена источника применяется после остановки и нового запуска.
2. Нажмите «Установить виртуальную камеру». Регистрация только HKCU, без администратора. Путь DLL сохраняется: удаляйте регистрацию до переноса папки. Уже установленную старую версию сначала удалите её rollback.cmd.
3. Перетаскивайте табличку в предпросмотре. При найденном лице это меняет смещение относительно лица; без лица переключает ручное размещение. «Прикрепить к голове» возвращает трекинг крупнейшего лица. При потере лица табличка держит последнее место 2 секунды от последней настоящей детекции. Затем включённый резервный режим плавно переносит её в правый нижний угол; выключенный скрывает. При возвращении лица слежение возобновляется плавно.
4. Выберите один из четырёх стилей, размер, масштаб BPM, смещения X/Y и сглаживание. «Без фона» оставляет только значок и число, без панели. Все настройки меняют тот же кадр, который получает виртуальная камера. Настройки V3 сохраняются после отпускания мыши в overlay-settings.bin рядом с EXE. Предпросмотр сохраняет пропорции 640×480.
5. В Discord выберите BandHeartBeat Virtual Camera. Поддерживается RGB24/RGB32 640×480, номинально 30 fps; реальный FPS зависит от камеры. Совместимость в живом звонке Discord ещё не проверена.

«Остановить» освобождает захват и убирает кадр из предпросмотра. Крестик и сворачивание скрывают приложение в трей, сохраняя виртуальный выход. Для полного завершения используйте «Выйти» в трее. Удаление камеры: кнопка «Удалить виртуальную камеру» или rollback.cmd, предварительно закройте использующие камеру приложения. Чужие записи не перезаписываются.

band-backend.exe — внутренний BLE/телеметрический процесс без окна; HTTP только localhost:8765, это не web-интерфейс приложения. При занятом порте приложение сообщает ошибку и не запускает захват. Не запускайте несколько версий одновременно. Без настоящей телеметрии на видео показано тире, в демо — 72 и маленькая отметка DEMO. Статусы связи и трекинга видны только в desktop-интерфейсе; служебных подписей на видео нет. Huawei Band 10 HR Broadcast не подтверждён; нужен стандартный BLE сервис 0x180D.

Windows FaceDetector работает локально на уменьшенном Gray8 кадре. При отсутствии API используется резервный режим. Качество трекинга живого лица и производительность CPU/GPU/памяти не измерены. Анимация иллюстрирует BPM, а не измеренное время отдельных ударов. Предпросмотр не перерисовывается в скрытом окне. Кадры не сохраняются и не загружаются в сеть.

Все зависимости в папке: native EXE/DLL используют статический CRT; Media Foundation и FaceAnalysis предоставляет Windows. OpenCV/ONNX, браузерный runtime и внешние модели не нужны. Без producer виртуальный фильтр показывает явно тестовый кадр. Физическая камера должна быть свободна; приложение не меняет настройки конфиденциальности.

Диагностика: camera-producer.exe --face-check; --self-test; --list; --mock --seconds 5. Регистрация: camera-admin.exe --register; откат: camera-admin.exe --unregister. Сборка из корня: cmd /c directshow-camera\package-msvc.cmd. Старые Rust/OBS артефакты сохранены отдельно.


## Переход на V11 и проверка Discord

1. Полностью завершите Discord через Quit/«Выйти» в его трее, а не только крестиком. Работающий процесс может держать старую DLL даже после успешной регистрации новой. Затем в старом BandHeartBeat выберите «Выйти» в трее и закройте другие потребители камеры. Программа не закрывает их автоматически.
2. Распакуйте V11 в постоянную отдельную папку. Запустите новый BandHeartBeat.exe. Внизу показаны установленная и текущая DLL: после установки оба пути должны указывать на BandHeartBeatDirectShow.dll именно в папке desktop-v11 (или вашей постоянной папке V11). Проверьте это также через camera-admin.exe --status.
3. Нажмите «Удалить виртуальную камеру», дождитесь результата HRESULT 0x00000000, затем «Установить виртуальную камеру». Если записи ещё нет, доступна сразу установка. Удаление проверяет только собственные CLSID/категорию и работает даже при отсутствующей старой DLL. Чужие/неопознанные записи сохраняются. Автоматических действий при старте нет.
4. Выберите источник и «Запустить», затем вновь откройте Discord и выберите BandHeartBeat Virtual Camera. Локальные graph-тесты не подтверждают совместимость именно с Discord; требуется ваш повторный тест.
5. Откат: закройте потребителей и новую программу, запустите rollback.cmd новой папки, затем install-current-user.cmd старой папки. Сохраняйте обе папки до проверки. Если новая установка не удалась, исправьте причину или зарегистрируйте старую версию её install-current-user.cmd. Установка не перезаписывает существующую запись.

Диагностика без изменения регистрации: camera-admin.exe --status. Явное удаление: camera-admin.exe --unregister, установка: camera-admin.exe --register. Ошибка выводит HRESULT, причину Windows и exit code в отдельном статусе регистрации. 0x800700B7: сначала Удалить, потом Установить. 0x80070005: владение не подтверждено или доступ запрещён; чужие записи не удаляются. 0x80070002: текущая DLL отсутствует — распакуйте все файлы вместе. Не требуется администратор/HKLM.

«Анимация» замораживает/возобновляет BPM-анимацию. «ЭКГ» включает дополнительную мини-кривую в остальных стилях. «Заполнение сердца» меняет заполнение/контур сердечных стилей. Кривая — иллюстрация BPM, не измеренная ЭКГ. Независимые переключатели сохраняются вместе с настройками.

30 fps — частота композиции и частота виртуального выхода по умолчанию. Потребитель может согласовать 5–30 fps (включая 15/20/24/25), и таймстампы/pacing будут соответствовать согласованной частоте. Медленная камера повторяет последний исходный кадр; это не30уникальных кадров камеры. Диагностический producer отдельно выводит unique captured/mock frames и repeated capture frames. Синтетический тест дал150кадров за5с; физическая камера в этой версии не проверялась.

Карточка V11 на30% уже:126px вместо180 при масштабе100%, без растяжения значков; трекинг,рамка,перетаскивание и угол используют тот же размер. Независимая проверка подтвердила локальное согласование FPS и ошибки запуска allocator; это не проверка Discord-звонка. При Pause/Resume остаются ограничения привязки timestamps к graph clock; восстановление после поздней ошибки worker отдельно не подтверждено.

V11 исправляет воспроизведённое краткое мерцание тестовой картинки при занятом IPC-mutex: последний проверенный кадр временно сохраняется вместо подмены шахматной картинкой. Возраст кеша проверяется при выборе каждого sample и ограничен2000мс от нового sequence; это не гарантия точного момента отображения на экране. При отсутствующем mapping/неверном заголовке кеш сбрасывается, при старом sequence/долгом ожидании выводится PLACEHOLDER-NO CAMERA. Независимый изолированный тест: до исправления18подмен за600мс,после0. Тип ваших реальных артефактов/результат Discord этим тестом не подтверждены.

## BLE discovery V11

Запустите только один экземпляр V11. Для демо без устройства используйте `--demo` — это явно помеченные72 BPM и не попытка подключения. Для живого запуска передайте необязательный hint: `BandHeartBeat.exe --ble-name "HUAWEI Band 10"` или `BandHeartBeat.exe --ble-address "AA:BB:CC:DD:EE:FF"` (адрес вводит пользователь; приватные адреса не встроены в программу). Сканирование также принимает рекламу стандартной службы0x180D. Совпадение имени/адреса лишь выбирает кандидата: после подключения программа обязана найти notify-характеристику0x2A37. Если её нет, показывается ошибка, а не ложный BPM. Не выполняйте одновременно обычный backend и V11: порт8765 должен принадлежать одному экземпляру. Появление часов в Bluetooth Windows не доказывает GATT HR service или уведомления. Поддержка Band10 не подтверждена.

## Зеркало камеры

Переключатель «Отразить камеру» отражает весь итоговый BGRA-кадр после композиции: preview и виртуальный выход получают одинаковое отражение, повторного mirror в DirectShow нет. Tracking/drag coordinates остаются в исходной системе координат; отражается финальный кадр. Изменение сохраняется в настройках V4 controls. Живой Discord mirror не проверялся.

Поиск часов выполняется через BLE backend hint `--ble-name`/`--ble-address`; отдельная native-кнопка поиска в compact panel пока не добавлена, поэтому используйте явный запуск V11 с параметром и смотрите статус `BLE candidate`, `missing 0x2A37` или `ожидаем пульс`.

## Найти часы

Кнопка «Найти часы» запускает отдельное ограниченное сканирование (до8с) без подключения для измерений и без pairing. Статус остаётся в нижней строке desktop и не заменяется статусом камеры. Возможные результаты: кандидат BLE, нет адаптера/кандидатов, `missing notify 0x2A37`, готов standard HR. Имя кандидата показывается, полный адрес не раскрывается. Для выбора можно передать `--ble-name` или `--ble-address` при запуске. Совпадение имени не доказывает поддержку пульса; Band10 и live Discord не проверены.

V11 ограничивает post-discovery BLE: connect8с, discover services8с, disconnect2с. Если найден Huawei HR-193, UI сохраняет имя кандидата и показывает точную фазу timeout/missing notify2A37; общий timeout helper30с — только последний safety-net.
