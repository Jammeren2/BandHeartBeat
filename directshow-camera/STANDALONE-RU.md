# BandHeartBeat — нативная виртуальная камера

Windows 11 x64. OBS и браузер для интерфейса не нужны. Распакуйте все файлы вместе в постоянную папку. Если запущена старая версия, завершите её через «Выйти» в трее перед запуском новой. Камера не включается автоматически.

1. Запустите BandHeartBeat.exe. Выберите физическую камеру по имени справа или «Демо · без камеры» и нажмите «Запустить». Смена источника применяется после остановки и нового запуска.
2. Нажмите «Установить для текущего пользователя». Регистрация только HKCU, без администратора. Путь DLL сохраняется: удаляйте регистрацию до переноса папки. Уже установленную старую версию сначала удалите её rollback.cmd.
3. Перетаскивайте табличку в предпросмотре. При найденном лице это меняет смещение относительно лица; без лица переключает ручное размещение. «Прикрепить к голове» возвращает трекинг крупнейшего лица. При потере лица включённый резервный режим переносит табличку в угол; выключенный скрывает её.
4. Выберите один из четырёх стилей, размер, масштаб BPM, смещения X/Y и сглаживание. Они меняют тот же кадр, который получает виртуальная камера. Настройки сохраняются после отпускания мыши в overlay-settings.bin рядом с EXE. Предпросмотр сохраняет пропорции 640×480.
5. В Discord выберите BandHeartBeat Virtual Camera. Поддерживается фиксированный RGB32 640×480, номинально 15 fps; реальный FPS зависит от камеры. Совместимость в живом звонке Discord ещё не проверена.

«Остановить» освобождает захват и убирает кадр из предпросмотра. Крестик и сворачивание скрывают приложение в трей, сохраняя виртуальный выход. Для полного завершения используйте «Выйти» в трее. Удаление камеры: кнопка «Установлена · удалить» или rollback.cmd, предварительно закройте использующие камеру приложения. Чужие записи не перезаписываются.

band-backend.exe — внутренний BLE/телеметрический процесс без окна; HTTP только localhost:8765, это не web-интерфейс приложения. При занятом порте приложение сообщает ошибку и не запускает захват. Не запускайте несколько версий одновременно. Без настоящей телеметрии показаны тире и DISCONNECTED, в демо явно DEMO · NO BAND, 72 BPM. Huawei Band 10 HR Broadcast не подтверждён; нужен стандартный BLE сервис 0x180D.

Windows FaceDetector работает локально на уменьшенном Gray8 кадре. При отсутствии API используется резервный режим. Качество трекинга живого лица и производительность CPU/GPU/памяти не измерены. Анимация иллюстрирует BPM, а не измеренное время отдельных ударов. Предпросмотр не перерисовывается в скрытом окне. Кадры не сохраняются и не загружаются в сеть.

Все зависимости в папке: native EXE/DLL используют статический CRT; Media Foundation и FaceAnalysis предоставляет Windows. OpenCV/ONNX, браузерный runtime и внешние модели не нужны. Без producer виртуальный фильтр показывает явно тестовый кадр. Физическая камера должна быть свободна; приложение не меняет настройки конфиденциальности.

Диагностика: camera-producer.exe --face-check; --self-test; --list; --mock --seconds 5. Регистрация: camera-admin.exe --register; откат: camera-admin.exe --unregister. Сборка из корня: cmd /c directshow-camera\package-msvc.cmd. Старые Rust/OBS артефакты сохранены отдельно.
